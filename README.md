# BISA - Campus Marketplace

**BISA** (Let's Do Business & Share Ideas) is a campus marketplace that connects students with student-owned businesses, products, and services. Students can discover businesses, make enquiries, contact sellers, and arrange payment or collection.

## Project Structure

- `index.html` - Homepage
- `explore.html` - Browse businesses and services with filters
- `business.html` - List your business (includes vendor policy popup)
- `about.html` - About BISA page
- `contact.html` - Contact us page
- `style.css` - Main stylesheet with BISA brand colors
- `assets/` - Images and logos

## Brand Colors

- **Berry Plum:** `#54234A` (primary)
- **Mango Gold:** `#FFB02E` (secondary)
- **Hot Coral:** `#F16B4B` (accent)
- **Warm Vanilla:** `#FFF1DA` (background)

## Deployment

This project is designed for deployment on Vercel. Connect the GitHub repository to Vercel and enable automatic deployments from the `main` branch.

## Development

No build step required - this is a static HTML website. Open any `.html` file in a browser to view locally.
